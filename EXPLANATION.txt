1. SYSTEM OVERVIEW & ARCHITECTURE
================================================================================

Mysterio is a high-performance, automated digital marketplace and service 
platform designed for instant delivery of digital products, accounts, software, 
and card inventory. 

The entire system is decoupled into modular components:

       +-------------------------------------------------------------+
       |                         END USERS                           |
       +-------------------------------------------------------------+
              |                                            |
              v (Web Browser: HTTPS)                       v (Telegram App)
       +--------------------+                     +------------------+
       |   Nginx Proxy      |                     |  Telegram Bots   |
       | (Port 80/443 SSL)  |                     | (Gateway/Stars/  |
       +--------------------+                     |  Dashboard/etc.) |
              |                                   +------------------+
              v (Port 3001)                                |
       +---------------------------------------------------+---------+
       |                  MYSTERIO WEB BACKEND                       |
       |                      (server.js)                            |
       +-------------------------------------------------------------+
              |                      |                      |
              v                      v                      v
       +-------------+        +-------------+        +---------------+
       |  JSON DATA  |        | NOWPayments |        | Chime Daemons |
       |  (data/*.json)       | Crypto API  |        | & IMAP Parser |
       +-------------+        +-------------+        +---------------+


Core Technologies:
- Web Engine: Node.js with native HTTP routing, session authentication, 
  and strict static file allowlisting.
- Frontend: Vanilla JavaScript, HTML5, CSS3 with responsive glassmorphism.
- Database: Atomic JSON flat-file storage in `/data` with automated schemas.
- Payment Methods: Account Balance, Crypto (NOWPayments), Chime (Automated 
  Email Matching), and Telegram Stars (Apple Pay & Google Pay).
- Process Manager: PM2 with unified `ecosystem.config.js`.

4. TELEGRAM BOT SUITE (Deep-Dive into Every Bot)
================================================================================

--------------------------------------------------------------------------------
4.1 GATEWAY BOT (`gateway_bot.js`)
--------------------------------------------------------------------------------
Purpose: 
Protects your official Telegram group/channel from spam, bots, and unauthorized 
users by acting as an automated gatekeeper.

How it works:
1. When a user requests to join your private Telegram channel, Telegram fires a 
   `chat_join_request` update.
2. The Gateway Bot catches this event, stores the user's pending request in 
   `data/gateway_sessions.json`, and sends the user a private message with an 
   interactive math captcha (e.g., "What is 7 + 5?").
3. When the user selects the correct inline button:
   - The bot approves the join request via Telegram API (`approveChatJoinRequest`).
   - The user is automatically admitted to the channel.
   - The user receives a welcome message with a link to `mysterio.cc`.
4. Admin features inside Gateway Bot:
   - `/admin` or `/stats`: Shows total verified users and active channels.
   - `/broadcast <HTML message>`: Mass-broadcasts an update to all verified users.

--------------------------------------------------------------------------------
4.2 PAYMENTS BOT (`payments_bot.js` — Telegram Stars)
--------------------------------------------------------------------------------
Purpose:
Allows customers to pay with Telegram Stars (funded directly via Apple Pay or 
Google Pay inside Telegram) for checkout or balance topups.

How it works:
1. On the Mysterio storefront (`cart.html` or `balance.html`), the customer 
   selects "Apple Pay / GPay (Telegram Stars)".
2. The website generates a unique order reference and opens a Telegram deep-link:
   `https://t.me/YourPaymentsBot?start=order_ORD-12345`
3. In `payments_bot.js`:
   - The bot queries the local store API (`/api/orders/details-stars?orderId=...`) 
     to retrieve the exact USD total and items list.
   - Calculates the required Telegram Stars amount (1 Star ≈ $0.02 USD).
   - Generates an official Telegram Invoice using `sendInvoice`.
4. The user completes the payment with 1-click Apple Pay / Google Pay.
5. Telegram sends `pre_checkout_query` (which the bot auto-approves) followed 
   by `successful_payment`.
6. The bot calls `server.js` (`/api/orders/complete-stars`) with `STARS_SECRET`.
7. `server.js` marks the order `COMPLETED`, allocates the digital credentials, 
   and displays them instantly on the user's screen.

--------------------------------------------------------------------------------
4.3 DASHBOARD BOT (`dashboard_bot.js` — Login & Real-Time Alerts)
--------------------------------------------------------------------------------
Purpose:
Connects the web account with Telegram for passwordless OTP logins and order alerts.

How it works:
1. Connecting Account:
   - User messages `/start` to Dashboard Bot.
   - The bot creates a unique token `TG-XXXXXXXX` in `data/users.json`.
   - The user enters this token on `mysterio.cc/login.html` under "Sign in with Telegram".
   - The bot immediately sends a 6-digit one-time code (OTP).
   - The user enters the 6-digit code on the website and is instantly logged in.
2. Real-Time Order Notifications:
   - When a purchase is completed, `server.js` calls `sendDashboardBotNotification()`.
   - The user gets an immediate receipt in Telegram with full credentials.
3. Administrator Remote Fulfillment:
   - For products marked as "Manual Delivery" (e.g. custom setups), admins can 
     complete the order directly inside Telegram by replying:
     `/complete ORD-XXXXXX <login details>` or `/done ORD-XXXXXX`

--------------------------------------------------------------------------------
4.4 REPLACEMENT BOT (`replacement_bot.js` — 24h Auto-Warranty)
--------------------------------------------------------------------------------
Purpose:
Automates customer warranty claims without requiring manual support staff.

How it works:
1. Customers have a 24-hour replacement window on eligible digital products and cards.
2. If an account or card is invalid, the customer clicks "Replace" in their 
   Orders page (`orders.html`), opening `https://t.me/mysterio_replacement_bot?start=replace_ORD123_0`.
3. The Replacement Bot:
   - Queries `server.js` (`/api/bot/order?orderId=...&secret=...`).
   - Verifies the order is within the 24-hour window and has not been replaced yet.
   - Prompts the user with confirmation buttons.
4. Auto-Swap:
   - The bot calls `/api/bot/replace-item`.
   - `server.js` automatically searches `inventory.json` / `products.json` for 
     an unsold item matching the exact same category, BIN, or variant.
   - Swaps the dead credential with fresh working credentials.
5. Auto-Refund Fallback:
   - If no replacement stock is available, the bot automatically credits the full 
     purchase amount back to the user's Mysterio balance via `/api/bot/refund-balance`.

--------------------------------------------------------------------------------
4.5 SUCCESS BOT (`success_bot.js` — Public Vouchers Feed)
--------------------------------------------------------------------------------
Purpose:
Builds buyer trust by automatically publishing anonymized purchase proofs to a 
public Telegram "Vouches / Proof" channel whenever an order is completed.

How it works:
- Polls `data/orders.json` for new `COMPLETED` orders.
- Masks sensitive details (e.g., "User J*** purchased 1x Spotify Premium for $4.00").
- Posts the proof receipt directly to the configured Telegram channel.

5. PYTHON DAEMONS & BACKGROUND SERVICES
================================================================================

--------------------------------------------------------------------------------
5.1 CHIME AUTOMATED MATCHING ENGINE (`chime_daemon.py` & `email_checker.py`)
--------------------------------------------------------------------------------
Chime offers zero-fee deposits, but lacks a public API. Mysterio overcomes this 
with an automated email parsing daemon:

1. Invoice Creation:
   - User selects "Chime" on `cart.html` or `balance.html`.
   - The site shows the store's Chime tag and creates a pending invoice with 
     the exact dollar amount in `orders.json` or `topups.json`.
2. Email Detection:
   - When the user sends money via Chime, Chime sends a notification email to 
     your Gmail address ("You received $25.00 from Jane Doe").
   - `chime_daemon.py` connects via IMAP (SSL Port 993) every 5 seconds.
   - Fetches unread emails from `notifications@chime.com`.
3. Extraction & Webhook Delivery:
   - Uses regex to extract: Sender Name, Sender Tag, Amount, Timestamp.
   - Sends an authenticated POST request to:
     `http://localhost:3001/api/payments/chime-webhook`
4. Server Matching:
   - `server.js` scans pending Chime invoices.
   - Matches the transaction by exact amount and sender tag (or 10-minute timestamp window).
   - Instantly marks the order `COMPLETED` or credits the user's balance.

--------------------------------------------------------------------------------
5.2 TELEGRAM USERBOT FORWARDER (`telegram_daemon.py`)
--------------------------------------------------------------------------------
- Powered by Python Telethon (MTProto).
- Monitors private supplier channels for product restocks and auto-forwards 
  them into your Mysterio announcement feed.

--------------------------------------------------------------------------------
5.3 GATEWAY DEPLOYER (`deploy_gateway.py`)
--------------------------------------------------------------------------------
- Automated Paramiko SSH/SFTP deployment script to install and restart the Gateway 
  bot on any isolated remote VPS with a single command.

6. ORDER, INVENTORY & BALANCE LIFECYCLE
================================================================================

Step 1: Browsing & Cart Addition
- Users can browse Products (`index.html`) or Card Inventory (`cards.html`).
- Products have customizable variants (e.g., 1 Month vs 6 Months) with separate 
  prices and stocks.
- When an item is added to the cart, client-side helper `cart-utils.js` maintains 
  the cart in `localStorage`.

Step 2: Checkout & Stock Reservation
- When checkout starts, `server.js` places a temporary lock on the items 
  (`PAYMENT_EXPIRY_MS` = 1 hour) to prevent double-selling.
- Supported Payment Methods:
  1. Balance: Deducts directly from user's `balance` in `data/users.json`.
  2. Crypto (NOWPayments): Creates an invoice for BTC, LTC, ETH, USDT, SOL, etc. 
     (includes automatic 10% crypto discount).
  3. Chime: Automated email matching.
  4. Telegram Stars: 1-click in-app Apple Pay / Google Pay.

Step 3: Instant Fulfillment & Delivery
- Once payment is confirmed:
  * For Instant Items: The line item credentials (e.g. `user:pass` or `CC|MM|YY|CVV`) 
    are extracted, attached to the order record in `data/orders.json`, and displayed 
    immediately on-screen.
  * For Manual Items: The order is marked `MANUAL_PENDING`, and admin bots are alerted.
- The user can view past purchases anytime under `mysterio.cc/orders.html`.

Step 4: Balance Top-Up Mechanism
- Users can pre-fund their account via `balance.html`.
- Crypto top-ups automatically receive a 10% bonus credit (e.g. deposit $100 -> credit $110).

8. STEP-BY-STEP DEPLOYMENT & HOSTING GUIDE (Ubuntu VPS)
================================================================================

Follow these steps to deploy Mysterio on a clean Ubuntu 22.04 or 24.04 VPS:

--------------------------------------------------------------------------------
STEP 1: Server Preparation & Dependencies
--------------------------------------------------------------------------------
Log into your VPS via SSH:
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl git nginx certbot python3-certbot-nginx python3-pip
```

Install Node.js (Version 20 or 22 LTS):
```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g pm2
```

--------------------------------------------------------------------------------
STEP 2: Deploy Mysterio Files
--------------------------------------------------------------------------------
Create the destination directory and copy your project files:
```bash
sudo mkdir -p /var/www/mysterio
sudo chown -R ubuntu:ubuntu /var/www/mysterio
cd /var/www/mysterio
```
(Upload your local Mysterio folder contents here using SCP, SFTP, or Git).

Install dependencies:
```bash
npm install
```

--------------------------------------------------------------------------------
STEP 3: Configure Environment Variables (.env)
--------------------------------------------------------------------------------
Edit your `.env` file with your real bot tokens, domain, and API keys:
```bash
nano /var/www/mysterio/.env
```
Fill in:
- `ADMIN_EMAIL` & `ADMIN_PASSWORD`
- `TELEGRAM_BOT_TOKEN` & `TELEGRAM_ADMIN_IDS`
- `NOWPAYMENTS_TOPUP_API_KEY` & `NOWPAYMENTS_ORDER_API_KEY`
- `PAYMENTS_BOT_TOKEN`, `GATEWAY_BOT_TOKEN`, `DASHBOARD_BOT_TOKEN`, `REPLACEMENT_BOT_TOKEN`

--------------------------------------------------------------------------------
STEP 4: Start Applications with PM2
--------------------------------------------------------------------------------
Start the entire ecosystem (storefront + all 5 bots) in one command:
```bash
cd /var/www/mysterio
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```
(Follow the on-screen command generated by `pm2 startup` to enable auto-reboot).

Check status:
```bash
pm2 status
pm2 logs mysterio-storefront
```

--------------------------------------------------------------------------------
STEP 5: Configure Nginx & SSL Certificate
--------------------------------------------------------------------------------
Copy the Nginx configuration file:
```bash
sudo cp /var/www/mysterio/mysterio.nginx.conf /etc/nginx/sites-available/mysterio.cc
sudo ln -s /etc/nginx/sites-available/mysterio.cc /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

Obtain a free SSL Certificate via Certbot:
```bash
sudo certbot --nginx -d mysterio.cc -d www.mysterio.cc
```
Certbot will automatically configure HTTPS, HTTP->HTTPS redirect, and auto-renewal.

Your site is now live at `https://mysterio.cc`!

9. TROUBLESHOOTING & MAINTENANCE CHEAT SHEET
================================================================================

1. Check Running Services:
   `pm2 status`

2. View Live Logs:
   `pm2 logs`                           # All processes
   `pm2 logs mysterio-storefront`       # Web server only
   `pm2 logs mysterio-payments-bot`     # Stars payments bot only

3. Restarting After Code Changes:
   `pm2 restart ecosystem.config.js`

4. Resetting Admin Password:
   Update `ADMIN_PASSWORD` in `.env` and restart `pm2 restart mysterio-storefront`.
   The server automatically syncs system credentials on startup.

5. Database Backups:
   All data lives in `/var/www/mysterio/data/`.
   To create an instant backup archive:
   `tar -czvf /home/ubuntu/mysterio_backup_$(date +%F).tar.gz /var/www/mysterio/data`
