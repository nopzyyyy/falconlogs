1. ARCHITECTURAL OVERVIEW
================================================================================

Mysterio is built as a high-performance, lightweight Node.js digital marketplace
designed for speed, resilience, and privacy.

- Core Web Engine: Node.js HTTP server (`server.js`) listening on port 3001.
- Reverse Proxy & SSL: Nginx handling ports 80/443 with Let's Encrypt TLS.
- Database Model: Flat-file JSON architecture in the `data/` directory.
  - `data/users.json`       -> Registered user profiles, hashed passwords, roles, balances.
  - `data/inventory.json`   -> Unique card stock inventory (PANs, CVVs, BIN metadata).
  - `data/products.json`    -> Digital catalog products, variant trees, custom products.
  - `data/orders.json`      -> Customer order records, fulfillment credentials, order states.
  - `data/topups.json`      -> Balance deposit invoices (Crypto, Chime, Telegram Stars).
  - `data/refunds.json`     -> Customer refund tickets, auto-checked validity, admin approvals.
  - `data/settings.json`    -> Dynamic payment method toggles, system settings.
  - `data/coupons.json`     -> Store discount codes and usage limits.
  - `data/announcements.json`-> Store banner announcements and alerts.
  - `data/faq.json`         -> Knowledgebase and FAQ questions.
  - `data/audit_logs.json`  -> Administrative action logs and timestamps.
  - `data/lockdown.json`    -> Site-wide Emergency Lockdown state.

* SQL Injection Immunity: Because there is no SQL database engine (no MySQL/Postgres/SQLite),
  SQL injection attacks are structurally impossible.

A. NOWPAYMENTS (CRYPTOCURRENCY GATEWAY)
---------------------------------------

B. CHIME AUTOMATED MATCHING SYSTEM
-----------------------------------
- Daemon (`email_checker.py` & `chime_daemon.py`):
  1. User initiates a Chime invoice and sends funds to the designated store Chime email.
  2. The background email checker polls the store inbox via IMAP for transaction emails from Chime.
  3. The parser extracts the sender tag, amount, and timestamp.
  4. The matching engine matches the transaction against pending records in `orders.json` or `topups.json`.
  5. Upon a match, the invoice is set to COMPLETED and credentials are auto-delivered.

6. HOW TO REHOST / REDEPLOY THIS SITE ON ANY SERVER
================================================================================

To start this website on a new Ubuntu/Debian VPS:

1. INSTALL PREREQUISITES:
   sudo apt update && sudo apt install -y nodejs npm nginx certbot python3-certbot-nginx

2. INSTALL PM2 PROCESS MANAGER:
   sudo npm install -g pm2

3. UPLOAD FILES:
   Extract this entire folder into `/var/www/mysterio/`

4. INSTALL DEPENDENCIES:
   cd /var/www/mysterio && npm install

5. CONFIGURE ENVIRONMENT (.env):
   Verify `.env` has the correct `PORT=3001` and your API keys.

6. START WITH PM2:
   pm2 start server.js --name "mysterio"
   pm2 save
   pm2 startup

7. CONFIGURE NGINX:
   Copy `mysterio.nginx.conf` to `/etc/nginx/sites-available/default`:
   sudo cp mysterio.nginx.conf /etc/nginx/sites-available/default
   sudo systemctl restart nginx

8. ENABLE SSL (HTTPS):
   sudo certbot --nginx -d yourdomain.cc -d www.yourdomain.cc

9. TO STOP HOSTING AT ANY TIME:
   pm2 stop all
   sudo systemctl stop nginx

10. TO RESUME HOSTING:
   pm2 start all
   sudo systemctl start nginx
